# 계모임 (igServer 예제 앱)

번호계·낙찰계를 지원하는 온라인 계(ROSCA) 앱. 여러 계원이 같은 계를 실시간으로 공유하며, 매 회차 곗돈을 모아 한 명이 목돈을 받습니다. igServer의 인증·데이터·실시간을 사용하고, 서버는 고치지 않고 igClient SDK만으로 붙였습니다.

## 실행

1. igServer를 켭니다.
2. 관리 대시보드(`/admin/`)에서 **계모임** 프로젝트를 만들고 API 키를 복사합니다.
3. 계 운영 엔진을 켭니다 (공정한 심판 역할):

   ```
   node public/apps/gyemoim/gye-engine.js --key=발급받은_키
   ```

4. 브라우저에서 앱을 엽니다 (여러 계원은 각자 다른 기기/시크릿창에서 접속):

   ```
   http://localhost:8787/app/gyemoim/?key=발급받은_키
   ```

## 동작

- 회원가입/로그인 → igServer 인증
- 계 개설(번호계/낙찰계, 인원·월납입액) → 초대코드 발급
- 계원이 초대코드로 참여 → 정원이 차면 엔진이 자동으로 1회차 시작
- 매 회차 전원이 곗돈 납입(에스크로 보관) → 수령자 결정
  - 번호계: 순번대로 수령
  - 낙찰계: 이자를 가장 많이 양보한 입찰자가 수령, 나머지만큼 곗돈에서 차감
- 납입 현황·입찰 현황이 모든 계원 화면에 실시간 반영 → igServer 실시간 브로드캐스트
- 전원이 목돈을 수령하면 계 종료

## 공정성 설계

계의 진행 상태(회차, 수령자)는 **계 운영 엔진만 소유하는 `gyestate` 문서**에 기록됩니다. 계원은 자기 납입·입찰만 만들 수 있고, 정산 결과는 건드릴 수 없습니다. igServer의 소유권 기반 권한 격리를 그대로 활용한 구조입니다.

메모리에 적힌 전체 스코프(자동이체, 연체 페널티, 보전기금, BNPL, 다통화, CB/PG/보험 어댑터)는 이 핵심 루프 위에 같은 방식으로 얹으면 됩니다. 결제·알림 같은 외부 연동은 엔진에 어댑터를 추가하는 자리입니다.
