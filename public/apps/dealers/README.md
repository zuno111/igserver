# 딜러스 (igServer 예제 앱)

"필요한 것" 한 줄을 올리면 딜러들이 하한가까지 경쟁 견적을 던지는 역경매 앱. igServer의 인증·데이터·파일·실시간을 모두 사용하며, 서버는 전혀 고치지 않고 igClient SDK만으로 붙였습니다.

## 실행

1. igServer를 켭니다 (`시작.bat` 또는 `bash start.sh`).
2. 관리 대시보드(`/admin/`)에서 **딜러스** 프로젝트를 만들고 API 키를 복사합니다.
3. 딜러 봇을 켭니다 (자동 딜러 4명):

   ```
   node public/apps/dealers/dealer-bot.js --key=발급받은_키
   ```

4. 브라우저에서 앱을 엽니다:

   ```
   http://localhost:8787/app/dealers/?key=발급받은_키
   ```

   (운영에서는 `?key=` 대신 index.html 안의 `DEALERS_KEY`에 키를 넣거나, 프로젝트별로 배포하세요.)

## 동작

- 회원가입/로그인 → igServer 인증(JWT)
- "필요한 것" 요청 등록(사진 첨부) → igServer 데이터 + 파일 업로드
- 딜러 봇이 새 요청을 WebSocket으로 즉시 감지 → 경쟁 견적을 3라운드에 걸쳐 인하
- 견적이 요청자 화면에 실시간으로 뜨고, 최저가가 표시됨 → igServer 실시간 브로드캐스트
- 요청자가 견적 수락 → 요청 상태 변경

딜러 봇의 가격 결정은 현재 규칙 기반(카테고리별 할인폭 + 하한가 클램프)입니다. 이 부분을 LLM 호출로 바꾸면 "AI 딜러"가 됩니다. 봇 구조는 그대로 두고 견적 계산 함수만 교체하면 됩니다.
