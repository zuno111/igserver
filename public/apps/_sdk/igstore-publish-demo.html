igStore 발행 위젯 데모

아래 내용을 작성하고 오른쪽 아래 "igStore에 올리기" 버튼을 누르면, 실제로 파일로 업로드되어 스토어에 발행됩니다. 이 위젯은 어떤 STUDIO ig 툴에나 스크립트 두 줄로 붙습니다.

igPlay 페이지에 붙이면 주소·키가 자동 주입되어 이 입력이 필요 없습니다. 데모에서는 직접 넣고 아래 "위젯 켜기"를 누르세요.

<script src="/app/_sdk/igclient.js"></script>
<script src="/app/_sdk/igstore-publish.js"></script>
<script>
  IGStorePublish.init({
    base: location.origin, key: 'igk_...',   // igPlay에선 자동 주입
    kind: 'asset3d',                          // webmax→asset3d, 레이어룸→image, 컷룸→video, IG Sound→music, GAE→asset3d/game
    getContent: async () => ({ blob: await exportGLB(), filename: 'model.glb' })
  });
</script>
